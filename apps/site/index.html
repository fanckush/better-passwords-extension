Questions

What is Hide My Email?

An iCloud+ feature that gives each site its own random address that forwards to your inbox. If a site sells or leaks it, you turn that one address off. Safari offers it in sign-up forms; this brings it to Chrome, using your iCloud sign-in in this browser.

Is this from Apple?

No. It's an independent, open-source extension that works with the Apple Passwords already on your Mac.

Is it safe?

Your passwords stay in Apple Passwords. The extension asks your Mac for the one you pick, fills it, and keeps nothing. There are no accounts, no servers and no tracking, and anyone can read the code. The security details are written down too.

How do I set it up?

Add the extension from your browser's store, then open the companion Mac app. It connects Chrome to Apple Passwords and turns on Touch ID. Unlock once, and turn on Hide My Email from the toolbar if you have iCloud+. Needs macOS 14 (Sonoma) or later.

What are the six digits?

When an extension connects to Apple Passwords, your Mac shows a six-digit code and you type it into the browser, to prove the browser is yours. Apple's extension needs a new one whenever Chrome puts it to sleep. This extension keeps the connection open for the browser session. With the optional companion app, Touch ID enters the code for you.

Do I need the companion app?

It's the easy way, and it's what adds Touch ID and your contact card's emails. Get it here. You can skip it, but setting up without it takes a few manual steps. See how.

Does it cost anything?

No. The extension and the companion app are free. Hide My Email is part of iCloud+, which you pay Apple for.

Does it work on Windows?

Not yet. It's Mac only for now, because it works with the Apple Passwords helper built into macOS. If you'd use it on Windows, open an issue to ask for it.
